# Idlebase — releases

Instaladores do **Idlebase**, o gerenciador de contas de jogos idle: todas as suas contas em uma só janela, cada uma com a própria sessão.

## Baixar

Na aba [Releases](../../releases/latest), escolha o arquivo do seu sistema:

- **Windows:** `Idlebase-Setup-X.Y.Z.exe`
- **Linux:** `Idlebase-X.Y.Z.AppImage` (dê permissão de execução: `chmod +x`)

O app instalado verifica sozinho se há uma versão nova aqui e só atualiza quando você clicar.

## Aviso sobre o Windows

O instalador ainda não é assinado digitalmente, então o Windows pode mostrar "O Windows protegeu o computador" na primeira instalação. Clique em *Mais informações* e depois em *Executar assim mesmo*.

## Sobre este repositório

Aqui ficam apenas os instaladores e os arquivos de versão que o app consulta para se atualizar. Seus dados (logins e configurações) ficam no seu computador e não são enviados a lugar nenhum.
